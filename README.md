# 🍔 2EZ4U Food Delivery - Project Struktur Data

Proyek ini adalah simulasi sistem antrean dan manajemen data pesanan untuk layanan pesan antar makanan **2EZ4U**. Proyek ini difokuskan pada implementasi dan analisis komparasi performa berbagai struktur data murni (tanpa menggunakan tipe data instan seperti `dict` atau *built-in library* Python).

## 📁 Struktur Repositori
Proyek ini memisahkan antara data mentah, logika sistem (*backend*), dan antarmuka pengguna (*frontend*):
* `data/` : Berisi dataset berformat `.csv` (`pesanan.csv` dan `peta.csv`).
* `backend/` : Berisi logika struktur data murni (Milestone 1-6).
* `frontend/` : Berisi antarmuka grafis (GUI) berbasis **Tkinter** untuk menguji dan memvisualisasikan performa backend.
